How it steps

∂ψ/∂t = ∇²[(r + (1+∇²)²)ψ + ψ³], grid spacing π/4, periodic.

Each step: ψ = F⁻¹ψ̂, g = ψ³ − Cψ, then ψ̂ ← Eψ̂ + Φ·Fg, with L = −K²(r + (1−K²)² + C), E = eLΔt, Φ = −K²(eLΔt−1)/L. That’s first-order exponential time differencing (ETD1).

K² is the Fourier symbol of the isotropic 9-point Laplacian, so the linear operator is exactly the 7×7 stencil, applied diagonally in Fourier space.

E, Φ and the FFT twiddles are computed in double precision (expm1 for small LΔt) and uploaded as f32. The state lives in Fourier space and Φ vanishes at k = 0, so the mean density is preserved exactly.

The cubic term is explicit; C is the linear stabilizer moved between the two sides. It’s set from the measured max ψ² so the frozen-coefficient amplification stays below one. Steady states don’t depend on C.

Noise is Philox4x32-10 keyed by (seed, stream), with stream 0 for the quench and stream 1 for reheat strokes, counter (cell, stroke) and u = (word₀ ≫ 8)·2⁻²⁴. philox.py reproduces it exactly. The same seed and the same strokes give the same run.

GPU f32 is f32 throughout. CPU f32 stores in f32 but does arithmetic in double. CPU f64 is double throughout. WebGPU has no f64.
