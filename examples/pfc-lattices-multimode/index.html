Seeding replaces the field with the target lattice, using every reciprocal point that lands on a favoured ring, fitted to the periodic box. Quench again instead to see which lattice the model picks on its own. Punching removes randomly chosen atoms; the removed mass spreads evenly, so the mean stays put.

How it steps

F = ∫ ψ(r + λ ∏ᵢ[(Qᵢ² + ∇²)² + bᵢ])ψ/2 − gψ³/3 + ψ⁴/4, conserved dynamics ∂ψ/∂t = ∇² δF/δψ, grid spacing π/4, periodic (the multi-mode model of Mkhonta, Elder and Huang). The product has a zero at each Qᵢ; the weight bᵢ lifts that minimum, so a larger bᵢ favours mode i less.

A lattice is stabilized when its reciprocal points sit on several favoured rings at once and those points form closed triads (G₁ + G₂ + G₃ = 0), which the ψ³ and ψ⁴ terms reward. Square needs rings at 1 and √2; a triangular lattice can use only one ring of a square-tuned set, so square wins once both are favoured.

Each step is first-order exponential time differencing with the exact spectral symbol: E = eLΔt, Φ = −K²(eLΔt−1)/L, L = −K²(r + λ∏ᵢ[(Qᵢ²−K²)² + bᵢ] + C), computed in double precision. The product grows like K4n, which the exponential absorbs exactly. The cubic and quartic terms are explicit with stabilizer C.

Checked headless (128², relaxing seeded candidates and comparing free energy): with Q = (1, √2), r = −0.5, ψ̄ = −0.45, square beats triangular, stripes and uniform. With one mode at ψ̄ = −0.25 triangular wins, at ψ̄ = +0.25 honeycomb, at ψ̄ = 0 stripes. Rectangular did not win for any weights tried, so that preset is a starting point for exploring, not a recipe.

Structure factor view: |ψ̂(k)|² of the stored spectrum on a log scale, k = 0 omitted, optionally averaged over frames. A crystal gives six Bragg spots on the ring at q₀ and weaker ones at √3 q₀. Grains rotate the spot sets and smear them into arcs; many grains make a ring. Vacancies lower the spots and add a flat diffuse haze plus faint lobes beside each spot along its radial direction (Huang scattering from the strain around each vacancy). Long averaging and a wide dynamic range bring out the diffuse parts.

Profiles: S(|k|) averages the structure factor over rings one k-pixel wide; the peak position and full width at half maximum are read off it. S(θ) averages over the first ring (centred on the measured peak) in 3° bins; spots are runs above half the maximum, and their mean width measures mosaic spread or arc length. Both use the same frame averaging as the view and update twice a second.

The cubic term is explicit; C is the linear stabilizer moved between the two sides. It’s set from the measured max ψ² so the frozen-coefficient amplification stays below one. Steady states don’t depend on C.

Noise is Philox4x32-10 keyed by (seed, stream), with stream 0 for the quench and stream 1 for reheat strokes, counter (cell, stroke) and u = (word₀ ≫ 8)·2⁻²⁴. Vacancy selection uses stream 6 with counter (atom cell, punch). philox.py reproduces it exactly. The same seed and the same strokes give the same run.

GPU f32 is f32 throughout. CPU f32 stores in f32 but does arithmetic in double. CPU f64 is double throughout. WebGPU has no f64.
