How it steps

F = ΣX=A,B ∫ ψX(rX + (1+∇²)²)ψX/2 + ψX⁴/4 + g ∫ ψAψB, with conserved dynamics ∂ψX/∂t = ∇² δF/δψX for each layer. g < 0 lowers the energy where both layers peak together; g > 0 where one peaks and the other dips.

The coupling is linear, so it goes into the exact part of the step: at each k the linear operator is a symmetric 2×2 matrix, and E = eLΔt and Φ = L⁻¹(eLΔt−I) are evaluated in closed form in double precision. Only the cubic terms are explicit, stabilized by a shared C.

Both real fields ride in one complex FFT, ψA + iψB, and are separated in Fourier space using Hermitian symmetry, so two layers cost the same as one. Each layer’s mean density is preserved exactly.

The plot uses F per unit area. The quadratic and coupling terms are summed exactly over k with the stepper’s own symbols; only ψ⁴/4 is summed in real space. Partial sums come off the GPU per workgroup and are finished in JS doubles. Gaps mark parameter changes and reheats, where F jumps. A flat floor late in a run is f32 round-off in F, not physics.

Noise is Philox4x32-10 keyed by (seed, stream): stream 0 quenches A, 2 quenches B, 1 and 3 reheat A and B, with counter (cell, stroke). philox.py reproduces it.
